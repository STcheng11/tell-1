# Animation guidance

The login/register and primary tab indicators use a flat, project-specific adaptation of
[smooth-option-switcher](https://github.com/zhoulinhua0-star/smooth-option-switcher)
by zhoulinhua0-star, installed at the user's request.

The implementation retains a persistent equal-width indicator, continuous reversible
CSS transitions, the reference easing curve, synchronized selected state, keyboard
support and reduced-motion behavior. Tell has no nested secondary selection here;
the nested Free/Premium/Monthly/Annual example is not reproduced.

The skill describes its example as a reconstruction of a video by 原子软糖At and
distinguishes reconstructed details from the original creator's source. This project
uses the adaptation guidance and does not claim to contain that creator's original
files or to reproduce the video pixel-for-pixel. Repository license and provenance:
[MIT / source boundaries](https://github.com/zhoulinhua0-star/smooth-option-switcher#5-mit-license).
